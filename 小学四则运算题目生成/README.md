# 小学四则运算题目自动生成与评测系统 

本项目为一个能够自动生成小学四则运算题目并进行答案判分的命令行工具，
使用 Python 3 实现，核心算法基于**表达式二叉树**进行语法建模，并采用**基于可交换算符排序的同构去重算法（Canonical AST）**，确保题目唯一性与算术规则合规。

---

## 2. 核心模块实现

### 2.1 分数工具模块 (`exercises/fraction_utils.py`)
*负责处理自然数、真分数和带分数的精准数值计算与文本双向转换。*

1. **数值范畴定义**：
   - **自然数**：分母为 1 的非负整数（如 `0`、`1`、`5`）。
   - **真分数**：依据需求说明（明确将带分数归入真分数范型），定义为化简后分母严格大于 1 的正有理数（$d \ge 2$ 且数值 $> 0$）。包含两类形态：
     - 纯真分数：分子小于分母（如 `1/2`、`3/5`）。
     - 带分数：分子大于分母且不可整除（如 `1’1/2`、`2’3/8`）。
2. **底层实现**：统一封装 Python 标准库的 `fractions.Fraction`，全程进行有理数无损计算。
3. **格式化输出 (`format_fraction(f: Fraction) -> str`)**：
   - 若分母为 1：输出自然数格式 `str(f.numerator)`（如 `0`、`3`）。
   - 若分子小于分母：输出纯真分数格式 `f"{f.numerator}/{f.denominator}"`（如 `3/5`）。
   - 若分子大于分母：输出带分数格式 `f"{q}’{r}/{f.denominator}"`，其中 $q = \text{numerator} // \text{denominator}$ 为整数部分，$r = \text{numerator} \% \text{denominator}$ 为真分数分子，连接符采用需求指定的 Unicode 右单引号 `’` (`\u2019`)（如 `2’3/8`）。
4. **文本解析与容错 (`parse_fraction(s: str) -> Fraction`)**：
   - **单引号兼容**：同时兼容中文右单引号 `’` (`\u2019`) 与英文 ASCII 单引号 `'` (`\u0027`)，解析前统一规范化。
   - **带分数解析**：拆解整数部分 $q$ 与分数部分 $a/b$，转换为标准分数 $\frac{q \times b + a}{b}$。
   - **纯真分数解析**：匹配到 `/` 时按纯分数转换为 $\frac{a}{b}$。
   - **自然数解析**：纯数字文本直接转换为 $\frac{s}{1}$。

### 2.2 表达式树与括号规则 (`exercises/tree.py`)
*使用二叉表达式树表示算式，叶子节点为数值，内部节点为运算符（`+`, `−`, `×`, `÷`）。*

1. **节点定义 (`TreeNode`)**：
   - 内部属性：`op`（操作符）、`val`（叶子数值 Fraction）、`left`、`right`。
2. **转中缀表达式与加括号算法 (`to_infix(node) -> str`)**：
   - 运算符优先级定义：`{ '+': 1, '−': 1, '×': 2, '÷': 2 }`。
   - **左子树加括号规则**：当 `left.op` 的优先级严格低于当前节点时加括号（如父节点为 `×`，左节点为 `+`，得到 `(a + b) × c`）。
   - **右子树加括号规则**：
     - 若 `right.op` 的优先级严格低于当前节点，必须加括号。
     - 若 `right.op` 的优先级等于当前节点，因数学文本遵循左结合律，右子树同级运算必须加括号以区分运算次序（如 $3 + (2 + 1)$ 与 $1 + 2 + 3$ 是同构题，而 $3 + 2 + 1$ 实际等价于 $(3 + 2) + 1$；右侧减法/除法同级运算 $a - (b - c)$、$a \div (b \div c)$ 亦必须加括号）。
   - 输出格式严格保证运算符及等号两边有空格。
3. **连续运算的左结合原则**：对未显式加括号的连续加减或乘除算式，严格遵循左结合律。

### 2.3 语法树交换律去重算法 (`exercises/tree.py`)
*题目要求：不能通过有限次交换 $+$ 和 $\times$ 左右算术表达式变换为同一道题。*

1. **规范化序列化 (`canonical_repr(node) -> str`)**：
   - 若为叶子节点：返回其最简分数对应的字符串标识。
   - 若为不可交换操作符（`−`、`÷`）：
     - 递归保持原顺序：`f"({canonical_repr(left)}{op}{canonical_repr(right)})"`。
   - 若为可交换操作符（`+`、`×`）：
     - 分别获取左右子树的标准化序列化字符串 $S_{left}$ 和 $S_{right}$。
     - **字典序排序**：比较两字符串的字典序，强制将较小的字符串排在左侧，较大的排在右侧：
       `f"({min(S_left, S_right)}{op}{max(S_left, S_right)})"`。
2. **去重判据验证**：
   - $1+2+3$（左结合，即 $((1+2)+3)$）与 $3+(2+1)$：经规范化后左右节点排定顺序完全一致，字符串相同，被判定为**重复**。
   - $1+2+3$ 与 $3+2+1$：树根组合的子表达式本质不同，规范化结果不一致，判定为**不重复**。
3. **查重存储**：将每棵树的规范化字符串存入全局 `set` 集合，实现 $O(1)$ 复杂度的碰撞检测。

### 2.4 题目生成与剪枝策略 (`exercises/generator.py`)

1. **算符与树结构采样**：
   - 运算符数量 $k \in \{1, 2, 3\}$（不超过 3 个），对应叶子操作数数量为 $k + 1 \in \{2, 3, 4\}$。
2. **数值注入（基于参数 `-r`）**：
   - 根据 `-r` 参数限制题目中数值与分母的范围（数值及分母均处于 $[0, r)$ 区间）：
     - **自然数叶子**：在区间 $[0, r)$ 内随机采样整数。
     - **纯真分数叶子**：随机生成分母 $d \in [2, r)$，分子 $n \in [1, d)$。
     - **带分数叶子**：随机生成整数部分 $q \in [1, r)$、分母 $d \in [2, r)$ 与真分数分子 $r' \in [1, d)$。
3. **业务规则即时剪枝（自底向上）**：
   - **减法非负剪枝（$e_1 \ge e_2$）**：若当前节点为减法 `−` 且 $val(left) < val(right)$，在二叉树上直接交换左右子树指针，实现 $e_1 \ge e_2$ 满足要求；若两子树值相等（差值为 0）符合非负要求，合法保留。
   - **除法必须为真分数剪枝（严格遵循需求定义）**：
     - 若当前节点为除法 `÷`，子表达式运算结果必须符合需求定义的“真分数”，即**计算结果必须为大于 0 且不可整除为自然数的正有理数**：
       - **合规判定**：除数 $val(right) \neq 0$、被除数 $val(left) > 0$，且最简结果分母 $val(left \div right).\text{denominator} > 1$。
       - **合法示例**：纯真分数（如 $1 \div 3 = 1/3$）与带分数（如 $3 \div 2 = 1’1/2$）均判定为合法。
       - **避免非法情况**：若被除数为 0（结果为自然数 0），或发生整除产生自然数（如 $4 \div 2 = 2$、$3 \div 3 = 1$），重新生成右子树叶子直到符合真分数约束。
   - **防死循环**：当 `-r` 极小（如 $r \le 2$）导致合法算式组合小于要求的`-n`时，设置单题尝试上限次数（Max Retry），防止生成器假死。当连续数千次尝试均无法产出新题目时，程序会主动捕获并退出。

### 2.5 批改求值模块 (`exercises/evaluator.py`)
*用于独立解析给定的题目文件与答案文件，计算并对比统计。*

1. **分词解析（Tokenizer）**：
   - 采用正则提取带分数、纯分数、整数、运算符及括号：`\d+[’']\d+/\d+|\d+/\d+|\d+|[+−×÷()]`。
2. **求值引擎（Shunting-Yard 逆波兰算法）**：
   - 使用双栈模型：操作数栈（存放 `Fraction`）与运算符栈（存放运算符与括号）。
   - 将中缀表达式转化为后缀形式并实时执行精准分数计算，求得标准答案。
3. **对错统计与输出**：
   - 逐行对比题目计算结果与给定的答案。
   - 记录正确题号与错误题号（索引自 1 开始）。（如数量为0，则输出空列表 `()`）
   - 格式化写入 `Grade.txt`：
     ```text
     Correct: 5 (1, 3, 5, 7, 9)
     
     Wrong: 5 (2, 4, 6, 8, 10)
     ```

---

### 2.6 命令行调度 (`main.py`)
使用 `argparse` 处理命令行输入，实现两种互斥模式：
1. **生成模式**：检查到 `-r` 参数（必需）与可选的 `-n` 参数（n默认为10），调用 `exercises.generator` 输出 `Exercises.txt` 和 `Answers.txt`。若缺少 `-r` 则终止并打印使用说明。
2. **批改模式**：检查到 `-e` 与 `-a` 参数，调用 `exercises.evaluator` 输出 `Grade.txt`。

## 3. 安装与使用说明

### 环境准备
* 运行环境：Python 3.10+
* 激活虚拟环境（Windows PowerShell）：
  ```powershell
  .\.venv\Scripts\Activate.ps1
  ```
  或者在未激活虚拟环境时直接调用虚拟环境中的 Python：
  ```powershell
  .\.venv\Scripts\python.exe main.py -n 10 -r 10
  ```
* 安装相关依赖（如果使用新环境）：
  ```bash
  pip install -r requirements.txt
  ```

### 命令行使用

#### 1. 题目生成模式
使用 `-r` 指定数值上限（必需，不包含该值），`-n` 指定题目数量（可选，默认 10）：
```bash
python main.py -n 10 -r 10
```
运行后将在当前目录生成：
* `Exercises.txt`：包含 10 道符合规范的四则运算题。
* `Answers.txt`：对应的标准答案。

#### 2. 答案批改模式
使用 `-e` 指定题目文件，`-a` 指定答案文件：
```bash
python main.py -e Exercises.txt -a Answers.txt
```
运行后将在当前目录生成：
* `Grade.txt`：记录批改结果及正确、错误的题目编号。
